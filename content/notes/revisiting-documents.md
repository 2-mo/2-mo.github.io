## LaTeX

- 在线：[Overleaf](https://www.overleaf.com/)。
- 本地：[TeX Live](https://tug.org/texlive/) + VS Code + [LaTeX Workshop](https://github.com/James-Yu/LaTeX-Workshop)。
- 文字辅助：[Grammarly](https://www.grammarly.com/)、[万词王](https://wantwords.net/)、[据意查句](https://wantquotes.net/)、[爱校对](https://www.ijiaodui.com/)。

## Markdown

编辑器：[Typora](https://typora.io/)、[MarkText](https://github.com/marktext/marktext)。VS Code 扩展：Markdown All in One、Markdown Checkboxes。

## 版本管理

Markdown 和 LaTeX 源文件可以用 Git 记录修改。入口：[Git](https://git-scm.com/downloads)、[《Pro Git》中文文档](https://git-scm.com/book/zh/v2)。
